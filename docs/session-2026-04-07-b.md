## Architecture Decisions

### Skill Level System
- `apply(p, level)` receives NEW level (1/2/3), applies only incremental delta
- Level 1 = current base effect, Level 2 = ~50% stronger, Level 3 = ~100% or unlocks merged skill
- Merged skills (Ball Lightning, Frost Nova, Mirror Ice) appear as Level 3 bonuses of their parent skill
- Ultimates gated behind regulars at level 2+ creates natural progression curve

### Hero Locking
- Simple `Set<HeroType>` for unlocked heroes — easy to expand later with meta-progression
- Visual feedback: procedural padlock, not an asset dependency
