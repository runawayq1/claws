## Lessons Learned

### Scene Lifecycle: stop() vs resume() Order
`scene.stop()` invalidates the ScenePlugin. If you call stop on the overlay scene BEFORE resuming the parent, the parent's resume call may fail. Always: `scene.resume(parent)` → `scene.stop(overlay)`.

### Phaser preload() Adds Latency Even When Empty-ish
Even with `textures.exists()` guards skipping all actual loads, having a `preload()` method triggers Phaser's loader pipeline. This added ~3-4 seconds of overhead. Removing redundant preload() methods was the biggest loading speed win.

### time.addEvent Doesn't Tick During preload
`this.time.addEvent()` timers don't fire during the preload phase. Use `this.load.on('progress')` to update UI during asset loading instead.

### Headless Chromium + WebGL
Headless Chromium uses SwiftShader (software WebGL) which can't handle large RenderTextures (3000x3000). Page crashes silently. Tests involving heavy WebGL must run headed.
