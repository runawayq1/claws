# Session 2026-04-08 — v0.4.2: Card UI, Mobile Polish, PWA Fixes

## Summary
Major UI overhaul for level-up cards, mobile stance controls, LoadingScene restoration, and chest spawn fixes.

## Changes

### Level-Up Card System
- Card backgrounds now use generated art (`card_back.png`, `card_sealed.png`) instead of procedural graphics
- All cards start face-down (sealed) — tap to flip with squeeze animation
- Hero/branch cards reveal with radial spark burst VFX in branch color
- Branch selection cards also sealed with dramatic 12-particle reveal burst
- Cards auto-scale on mobile to fit screen width (computed scale factor per device)
- Removed "?" text from sealed cards — clean sealed art only

### Mobile Stance Controls
- Replaced small bottom-right button with right-half-of-screen tap zone
- Small emoji indicator (bottom-right, 0.6 alpha) shows current stance
- Fixed non-working button: container interactive hitArea with `Geom.Circle.Contains`

### Mobile UI Scaling
- UIScene: camera zoom 0.92 on mobile for slight UI reduction
- LevelUpScene: camera zoom 0.85 on mobile + responsive card scaling
- Branch selection header text scales down on mobile (28px vs 40px)

### LoadingScene Restored
- Hero selection now routes through LoadingScene (`StartScene → LoadingScene → GameScene`)
- LoadingScene registered in main.ts scene array
- Progress bar shows asset loading, flavor text cycles, terrain-ready signal from GameScene

### Chest Spawn Fixes
- Chests no longer overlap each other (inter-chest distance check added)
- Rock exclusion zone increased from 80px to 120px (accounts for 1.8x rock scaling)

### Orb Lifetime
- XP orbs: 20s → 30s
- Gold orbs: 25s → 30s

### Skills & Docs
- Installed `/ui-ux-pro-max` skill from GitHub (nextlevelbuilder/ui-ux-pro-max-skill)
- Skill docs sync in progress (dalle prompts + skill descriptions)

## Architecture Notes
- Card scaling uses `container.setScale(cardScale)` where `cardScale = min(1, availableWidth / totalCardsWidth)`
- Sealed cards are a sub-container with `card_sealed` image + border graphics, hidden on flip
- Mobile stance zone: invisible `Phaser.GameObjects.Zone` covering right 50% of screen at depth 5
- `isChestPositionClear()` now checks: other chests → rocks (120px) → trees (150px) → decorations (80px)

- `src/scenes/LevelUpScene.ts` — card backgrounds, sealed/flip system, mobile scaling
